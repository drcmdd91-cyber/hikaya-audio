# قالب الإخراج العمودي — دفتر الحكايات
## الوضع الحالي
برنامج أولي يركّب فيديو عمودي 1080×1920:
- أعلى 480 بكسل: **صورة غلاف خاصة بالقصة** تحتوي على اسم القناة «دفتر الحكايات» وعنوان القصة، ويُنشئها مصمم الغلاف لكل فيلم.
- الوسط 1100 بكسل: الفيديو، دون قص محتواه.
- أسفل 340 بكسل: مساحة للترجمة والتسميات باستخدام ملف ASS اختياري.

### الاستخدام
```bash
python studio/layout/render_layout.py --video part1.mp4 --cover cover_part1.png --subtitles part1.ass --output finished_part1.mp4
```
تحتاج FFmpeg مع دعم libass للترجمة. الملف الناتج لا يعني صحة توقيت النص أو تطابقه مع الأحداث؛ هذا يُراجع قبل النشر.

### ضمانات التصميم
- لا توجد صورة غلاف عامة ثابتة؛ الغلاف لكل قصة وجزء.
- الثابت فقط اسم القناة، ويجب أن يكون داخل صورة الغلاف.
- لا تستخدم ترجمة إنجليزية محروقة في الفيديو الأصلي.
- يجب التحقق من مواضع عناصر واجهة تيك توك على عينة منشورة قبل اعتماد الهوامش.

### حالة التحقق
**تم إنشاء الكود، ولم يختبر بعد على فيلم كوريا أو اعتماد قالب نهائي.**
