# استديو الأداء الصوتي العربي — دفتر الحكايات
## المبدأ
لا يُقرأ السيناريو كله بصوت واحد. الراوي يؤدي الحدث، وكل شخصية لها هوية صوتية ثابتة، مع توجيه الأداء حسب السياق.

## دورة الإنتاج
1. السيناريو العربي الكامل والمشكّل، مع تحديد المتحدث لكل جملة.
2. قاموس نطق للأسماء والمصطلحات والسنوات والأرقام.
3. سجل ثابت لأصوات الشخصيات: narrator / jace / saud ... دون استنساخ صوت شخص حقيقي بغير إذن.
4. وسوم أداء: calm, suspense, urgency, fear, relief, excitement, whisper, radio.
5. توليد كل سطر مستقلًا بمحرك صوت يدعم العربية والتحكم بالأداء، ثم سماعه ومراجعته.
6. مطابقة السطر مع توقيت المشهد، وفحص حوار الشخصيات ومؤثرات الراديو.
7. أي نطق غير صحيح أو هوية صوتية غير متسقة تعيد السطر إلى الإصلاح قبل المونتاج.

## درجات الجاهزية
- **منفذ:** مدقق هيكلي للسيناريو وقاموس نطق ونموذج الشخصيات.
- **غير منفذ بعد:** محرك توليد صوت محلي عربي متعدد الشخصيات، وتقييم سمعي آلي للنطق.
- **إلزامي:** مراجعة سمعية فعلية قبل اعتماد الدبلجة.
