# معمارية استديو دفتر الحكايات — نظام نملكه ونطوره
## وحدات الإنتاج
1. إدارة المشاريع والسيناريو — JSON وقوالب ومراجعة اكتمال النص.
2. فهرسة المشاهد — FFmpeg/ffprobe واكتشاف تغيّر اللقطات؛ التحقق الدلالي يتطلب مشاهدة.
3. التفريغ والترجمة — whisper.cpp أو faster-whisper؛ تدقيق عربي يدوي قبل الدبلجة.
4. أصوات الشخصيات — واجهة محركات قابلة للتبديل (Piper / Chatterbox / VoxCPM أو أي محرك يثبت دعمه للعربية وترخيصه). **غير مثبتة بعد**.
5. محرّك مونتاج مملوك لنا — studio/engine.py باستخدام FFmpeg، يأخذ cue sheet، ويخرج فيديو لكل جزء؛ لا يركب حوارًا إنجليزيًا تلقائيًا.
6. الأغلفة — قوالب متغيرة لكل جزء؛ وحدة التنفيذ **قيد التطوير**.
7. ضمان الجودة — studio/check_project.py + اختبار بشري للصوت والصورة + ffprobe؛ لا نشر عند نقص أي تحقق.
8. النشر — موصل Metricool متصل عند توافر صلاحية الفعل؛ لا يفترض نجاحًا حتى يرجع رابط.
9. التعلم بعد الإنتاج — CHANGELOG.md وLESSONS_LOG.md واختبارات انحدار.
## سياسة التكلفة
- افتراضيًا استخدم البرمجيات الحرة والأدوات المحلية أو GitHub Actions حيث تسمح الحصص.
- لا تدفع ولا تشترِ خدمات أو موارد GPU دون موافقة المستخدم.
- التوليد السينمائي الثقيل قد يتطلب GPU/وقت/استضافة؛ هدف 15 دقيقة غير مضمون لكل مدة.
