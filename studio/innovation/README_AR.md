# مدير التطوير والابتكار — دفتر الحكايات
مدير استكشاف تقني دوري يبحث عن أدوات وقوالب إنتاج جديدة ويضعها في طابور الاختبار.
**الحالة:** نظام اكتشاف وتقارير، وليس وكيلًا يثبّت أدوات تلقائيًا أو يضمن جودة النتائج.

## الدورة
اكتشاف → تصفية الرخص والمخاطر → تقييم → تجربة معزولة → قياس → اعتماد → دمج → اختبار انحدار → توثيق الإصدار.

## مجالات البحث
- توليد فيديو وصور محلي، تحريك 3D وBlender، مؤثرات بصرية.
- دبلجة عربية، تحويل النص إلى صوت، فصل أصوات، مزامنة شفاه.
- المونتاج، الترجمة والتسميات، المخططات والرسوم العلمية.
- قوالب غواصات وطائرات ومبانٍ وتشريح، وأغلفة وأصول مرخصة.

## شروط الاعتماد
1. ترخيص مناسب للاستخدام التجاري ومصدر موثوق.
2. دعم العربية عند الحاجة.
3. تشغيل وتجربة عينة ممثلة في بيئة معزولة.
4. مقارنة الجودة والسرعة والتكلفة مع الحل الحالي.
5. فحص أمان للتبعيات، ومنع التنفيذ العشوائي لشيفرات خارجية.
6. لا دفع أو إنشاء اشتراك أو نشر دون إذن.
7. تحديث CHANGELOG.md وإضافة اختبار يمنع التراجع.

## التشغيل
- workflow: `.github/workflows/innovation-scout.yml` يوميًا ويدويًا.
- `studio/innovation/scout.py` يبحث في GitHub API وينتج تقرير JSON وMarkdown.
- نتائج البحث **مرشحون فقط**، وليست إضافات مثبتة.
- كل تقرير يحفظ كـ GitHub Actions artifact ويُفتح Issue واحد للمراجعة عند وجود مرشحين.
- قيود GitHub Actions والحصص والاتصال قد تمنع التشغيل؛ يجب مراجعة سجلات التشغيل.

## بطاقة التقييم
`candidate_id`, `url`, `license`, `commercial_use`, `arabic_support`, `hardware`, `security_review`, `benchmark_quality`, `benchmark_speed`, `integration_cost`, `status`, `evidence`.
